# 批量下载器

批量下载任意公开文件链接的 Chrome 扩展：粘贴链接后自动识别文件名、按日期归类保存；Google Drive 分享链接可自动跳过「病毒扫描确认」页。

## 功能

- **任意链接**：不限来源，支持任意 http / https 文件链接；网页链接（HTML）不会当成文件写盘，会在新分页打开。
- **自动识别文件名**：按 Content-Disposition > 网址路径 > Content-Type 的顺序推断；下载接口式路径（/download、/uc 等）不会被当成文件名。
- **按日期归类**：保存到固定文件夹时，自动按当天日期（MMDD）建子文件夹；同名文件自动加 `(1)`，不覆盖。
- **Drive 确认页跳过**：Drive 大文件「病毒扫描确认」页自动识别并跳过；跳不过时在新分页打开，请手动点「仍然下载」；配额用完时会在提示里说明。
- **三种保存方式**（设置页可选）：自动（有固定文件夹就用它，否则改用浏览器下载）/ 只用固定文件夹 / 只用浏览器下载。
- **批量**：一次最多 500 个链接，可暂停、继续、重新下载失败项；失败与已新开分页的链接可一键复制。
- **打开文件夹**：全部下载结束且至少成功 1 个时，底部「清空」和「全部下载」中间会出现「打开文件夹」按钮；浏览器下载的文件会定位到该文件，固定文件夹模式下打开浏览器默认下载文件夹并用气泡报出本次真正的保存位置。
- **文件大小**：识别列表每行右侧显示文件大小（下载完成后的实际字节数），拿不到的显示「大小未知」；下载完成时还有一行汇总（成功 / 失败个数与总大小）。
- **固定高度**：粘贴框 88px、文件列表固定 260px 高，文件再多也只在列表内上下滚动，窗口总高度不变。
- **版本药丸与更新检查**：页头右侧有个版本号药丸（`v1.0.0`），打开时静默检查 GitHub 有没有新 Release，有新版时药丸变橙色并弹出更新窗口；点药丸可以手动再查一次（1 分钟最多 3 次）。更新窗口里有关闭、「暂时忽略」和「前往下载」，更新仍需手动下载 zip 覆盖插件文件夹。

## 安全与隐私

- **链接不上传**：你贴的链接只用来向它自己的源站发请求、写入本地磁盘或新开分页，不上传到别处；扩展仅有的对外请求是：下载你贴的链接、以及检查更新时向 GitHub API 请求公开的最新 Release 信息（只含版本号与说明，不含你的任何数据）。
- **文件名已净化**：路径穿越（`../`）、Windows 保留名、控制字符与双向覆盖字符都会被处理，不会写出目标目录。
- **无第三方依赖、无远程代码**：全部代码都是本扩展自己的文件，不加载任何外部脚本；没有硬编码的认证 Token。

## 安装（加载已解压的扩展程序）

1. 在 GitHub Releases 里下载最新版本的 zip，解压到一个文件夹（不要删除这个文件夹，扩展要一直从这里读取）。
2. 打开 Chrome，进入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择刚才解压出的文件夹（里面有 `manifest.json`）。
4. 点工具栏的扩展图标打开「批量下载器」，在设置页选择保存文件夹（不选也能下载，会改用浏览器默认下载文件夹）。

更新时：有新版时药丸变橙色并弹出更新窗口，点「前往下载」下载新版 zip，解压覆盖旧文件夹，然后在 `chrome://extensions` 里点「重新加载」（移除前请确认已下载的文件都在）。仅点「重新加载」不会清空已保存的设置。

## 使用

- **粘贴链接**：把文件链接粘贴到输入框，每行一个，也可混在文字里；支持 Markdown `[文字](链接)`、尖括号与引号包裹的链接，行尾多余标点会自动去掉。
- **Drive 链接**：直接粘贴 Drive 分享链接即可（`drive.google.com/file/d/.../view`、`open?id=...`、`uc?id=...`）；Drive 文件夹链接无法直接下载，会提示。
- **下载**：点「全部下载」，可中途暂停；下载完失败的项可以只重下失败项；下载完成且至少成功 1 个时，点「打开文件夹」可打开本次下载保存的文件夹。
- **文件大小**：列表每行右侧是该文件的大小，下载前显示「大小未知」，下载完成后补上实际大小。
- **保存位置**：设置页可更换保存文件夹与下载方式；文件夹授权失效时会提示重新授权，未修复时自动改用浏览器下载，不会卡住。

## 常见问题

- **版本号药丸变橙色了？** 说明 GitHub 上有了新版本。点药丸或等打开时的提醒窗口，确认后去 Releases 下载新版；不想更新就点「暂时忽略」。
- **提示「该链接返回的是网页」？** 该链接返回的是 HTML 网页（登录页、错误页或普通网页），不是文件，已在新分页打开，请在新分页里手动处理。
- **Drive 提示无法自动跳过确认页？** 确认页结构变化导致无法自动识别，已在新分页打开，请手动点「仍然下载」；如果提示里写了配额用完，需要等待或更换账号。
- **下载的文件去哪了？** 固定文件夹模式下在「你选的文件夹 / 当天日期（MMDD）」里；浏览器下载模式下在浏览器默认下载文件夹的当天日期子文件夹里。
